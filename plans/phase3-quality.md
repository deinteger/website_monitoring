# 3단계 — 전자정부 공식 품질진단 확장

1·2단계가 안정화된 후 시작한다. 이 단계에서만 `docs/quality-guide-map.md`와 전자정부
웹사이트 품질관리 가이드 PDF의 필요한 쪽을 확인한다. HWPX와 PDF가 동일하면 PDF만
읽는다.

- [ ] 적용범위와 제외항목 재확인
- [ ] 대표 페이지 선정 규칙
- [ ] 자동진단·수동진단 항목 분리
- [ ] 공식 배점 계산
- [ ] 수동점검 체크리스트와 증거화면 관리
- [ ] 공식 품질진단 결과서
- [ ] 자동 사전진단과 공식 진단 결과의 표시 구분

초기 전체 구현 제외항목인 이미지·자료 출처, 표 제목셀, 비표준 플러그인,
`robots.txt`는 사용자가 명시적으로 다시 요구하기 전에는 포함하지 않는다.
