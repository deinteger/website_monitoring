# 일일 점검항목 및 판정기준

## 1. 페이지·메뉴 변동

- 메인 메뉴, 전체 메뉴, sitemap.xml에서 수집한 전체 URL
- URL별 발견 출처와 수집원별 URL 수
- 신규·삭제·변경 페이지
- 메뉴에서 연결되지 않는 페이지
- 중복 URL
- 빈 페이지
- HTTP 200 상태의 오류화면(Soft 404) 후보

메뉴 경로는 가능한 깊이까지 `1차 메뉴 > 2차 메뉴 > 3차 메뉴` 형식으로 저장한다.
같은 URL이 여러 수집원에서 발견되면 URL은 하나로 통합하되 발견 출처는 모두 보존한다.

## 2. 콘텐츠 최신성·신뢰성

- 게시일자·수정일자
- 오래된 콘텐츠와 기준연도
- 종료된 행사·신청·공고
- 오래된 조직명·부서명·담당자·연락처 후보
- 게시일자 점검 불가
- 규칙 기반 오탈자 후보
- 개인정보 노출 의심
- 게시일이 표시되는 목록형 콘텐츠의 최신 게시일
- 최신 게시일이 실행 기준일보다 달력 기준 3개월 이상 오래된 `게시 최신성 지연`

단순히 게시일자가 오래되었다는 이유만으로 오류로 확정하지 않는다. 콘텐츠 유형,
시효성 표현, 아카이브 여부를 반영해 `정상`, `검토 필요`, `오류`, `점검 불가`로
구분한다. 개인정보 의심 값은 마스킹하고 공개 업무연락처 예외를 고려한다.

달력 기준 3개월은 90일로 환산하지 않는다. 예를 들어 실행 기준일이 8월 25일이면
5월 25일 이하의 최신 게시일을 `게시 최신성 지연`으로 분류한다. 해당 분류는 사이트
장애가 아니라 현행화 검토대상으로 처리한다.

## 점검범위·실패 기록

- 수집원별 발견 URL 수
- 정규화 전·후 URL 수와 중복제거 수
- 점검 성공·실패·제외 URL 수
- 누락된 메뉴·페이지와 누락 사유
- HTTP·파싱·차단·timeout 등 실패 단계와 사유
- 오류 또는 수동확인 항목의 스크린샷 경로

스크린샷은 모든 정상 페이지에 생성하지 않고 오류·변경·수동확인 증거가 필요한
페이지에만 생성한다. 브라우저를 사용할 수 없는 경우 `스크린샷 생성 불가` 사유를
기록한다.

## 3. 링크·이미지·첨부파일

- 내부·외부 링크 4xx·5xx·timeout
- 리다이렉트 최종 목적지와 과도한 리다이렉트
- 페이지 내 앵커 오류
- 깨진 이미지와 이미지 `alt` 누락
- 첨부파일 다운로드 실패·크기 0·형식 불일치·손상
- CSS·JavaScript 리소스 오류

첨부파일은 `HEAD`를 우선 사용하되 서버가 HEAD를 지원하지 않거나 결과가 모호하면
용량을 제한한 GET 또는 Range GET으로 재확인한다. `Content-Length: 0`만으로 오류를
확정하지 않는다.

## 4. 웹표준·접근성 기초

- HTML5 문서 선언
- UTF-8 문자 인코딩
- HTML 기본 문법 후보
- 페이지 제목
- 문서 기본 언어
- 중복 ID
- 입력서식 레이블
- 빈 링크·빈 버튼
- 반복영역 건너뛰기 링크
- 모바일 viewport
- 이미지 대체텍스트

자동으로 의미의 적절성까지 판단하기 어려운 항목은 `수동확인 필요`로 표시한다.

제외:

- 표 제목셀
- 비표준 플러그인
- 이미지·자료 출처

## 5. 접속상태·성능

- HTTP 상태
- 응답시간
- 페이지 전송용량
- JavaScript 콘솔 오류(브라우저 모드 사용 시)
- SSL 오류
- 혼합 콘텐츠
- 403·429·WAF 차단
- sitemap.xml 접속·구조 오류

전자정부 가이드의 3초·3MB 기준은 참고값으로 제공하되, 로컬 측정 결과를 공식
WebPageTest 점수라고 표시하지 않는다.

제외:

- robots.txt 및 검색로봇 차단 여부

## 심각도 기본값

- 상: 사용자가 페이지·파일에 접근할 수 없는 오류
- 중: 오래되거나 잘못된 정보, 주요 기능 오류
- 하: 경미한 품질·접근성 문제
- 검토: 자동확정이 어려워 사람 확인이 필요한 후보

## AI 보조점검

AI는 규칙검사를 대체하지 않고 다음 후보를 재검토한다.

- 변경된 페이지의 오래된 정보·시효성 문구
- 규칙 기반 오탈자 후보와 어색한 문장
- 제목과 본문 내용의 불일치 가능성
- 오류에 대한 개선 권고안

전체 페이지를 매일 다시 전송하지 않는다. 콘텐츠 해시가 변경됐거나 규칙검사에서
후보가 나온 페이지만 전송하고 결과를 캐시한다. AI 판정은 `검토 필요`이며 URL·근거
문구 없이 단독으로 오류를 확정하지 않는다.
