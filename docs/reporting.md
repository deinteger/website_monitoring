# 결과서 구성

## 파일 1. 페이지별 점검결과

파일명: `페이지별_점검결과_YYYY-MM-DD.xlsx`

### 시트 1. 종합현황

상단에는 사이트별 요약을 표시한다.

| 사이트 | 전체 페이지 | 정상 | 검토 필요 | 오류 | 점검 불가 | 신규 | 삭제 |
|---|---:|---:|---:|---:|---:|---:|---:|

하단에는 두 사이트의 전체 메뉴와 모든 페이지를 메뉴 순서대로 표시한다. 정상 페이지도
반드시 포함한다.

| 사이트 | 1차 메뉴 | 2차 메뉴 | 3차 메뉴 | 페이지 제목 | URL | 최신성 | 링크·자료 | 웹표준·접근성 | 접속상태 | 종합결과 | 오류 수 |
|---|---|---|---|---|---|---|---|---|---|---|---:|

요구사항:

- URL을 클릭 가능한 하이퍼링크로 제공
- 자동필터와 틀 고정
- 정상·검토·오류·점검불가 색상 구분
- 메뉴 외 페이지는 별도 표시
- 오류 수 또는 판정을 누르면 상세 시트로 이동

### 시트 2. 콘텐츠 최신성·신뢰성 상세

| 사이트 | 메뉴 경로 | 페이지 제목 | URL | 게시일자 | 발견 연도 | 문제 유형 | 판정 방식 | 판정 | 신뢰도 | 근거 문구 | 개선 권고 | 점검일시 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

`판정 방식`은 `규칙`, `AI 보조`, `수동` 중 하나로 표시한다. AI 결과는 신뢰도와
근거를 함께 표시하며 종합현황에서 자동확정 오류로 집계하지 않는다.

### 시트 3. 링크·이미지·첨부파일 상세

| 사이트 | 메뉴 경로 | 원본 페이지 | 원본 URL | 대상 유형 | 대상 URL | HTTP 상태 | 최종 URL | 문제 유형 | 심각도 | 개선 권고 |
|---|---|---|---|---|---|---|---|---|---|---|

### 시트 4. 웹표준·접근성 상세

| 사이트 | 메뉴 경로 | 페이지 제목 | URL | 점검항목 | 결과 | 오류 위치 | 증거 내용 | 심각도 | 개선 권고 |
|---|---|---|---|---|---|---|---|---|---|

### 시트 5. 접속상태·성능 상세

| 사이트 | 메뉴 경로 | 페이지 제목 | URL | HTTP 상태 | 응답시간 | 페이지 용량 | 콘솔 오류 수 | SSL | 혼합 콘텐츠 | 판정 |
|---|---|---|---|---:|---:|---:|---:|---|---|---|

세부 시트에는 오류·검토 필요·점검 불가 항목만 표시한다. 정상 여부는 종합현황에서
확인한다.

### 시트 6. 점검범위·누락·실패

상단에는 수집원별 범위를 표시한다.

| 사이트 | 수집원 | 발견 URL | 정규화 후 | 중복제거 | 점검 성공 | 점검 실패 | 제외 |
|---|---|---:|---:|---:|---:|---:|---:|

하단에는 누락·실패 상세를 표시한다.

| 사이트 | 메뉴 경로 | URL | 발견 출처 | 실패 단계 | 실패 사유 | 재시도 여부 | 스크린샷 | 점검일시 |
|---|---|---|---|---|---|---|---|---|

## 파일 2. 검색포털 오류결과

파일명: `검색포털_오류결과_YYYY-MM-DD.xlsx`

### 시트 1. 종합현황

| 사이트 | 검색포털 | 수집 URL | 정상 | 오류 | 신규 | 지속 | 해결 | 마지막 수집일 |
|---|---|---:|---:|---:|---:|---:|---:|---|

### 시트 2. 오류 상세

| 사이트 | 검색포털 | 검색 질의어 | 검색결과 제목 | 노출 URL | HTTP 상태 | 최종 URL | 문제 유형 | 상태 | 최초 발견일 | 최근 확인일 | 개선 권고 |
|---|---|---|---|---|---:|---|---|---|---|---|---|

## 출력 검증

- 두 파일이 실제 생성되었는지 확인
- 필수 시트와 컬럼 확인
- 행 수와 종합현황 집계 일치 확인
- 하이퍼링크와 필터 작동 확인
- 날짜·시간대는 Asia/Seoul 사용
- 빈 결과도 시트와 헤더를 유지하고 `오류 없음`을 표시
- 오류·변경·수동확인 증거 스크린샷은 `screenshots/YYYY-MM-DD/`에 저장하고
  결과서에서 해당 파일을 연결
- API 키·전체 프롬프트·모델 내부 추론을 결과서에 기록하지 않음
